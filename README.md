# Akhil Chelat — Developer Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For the best local development experience, use VS Code Live Server.

## Personalize before publishing
Open `config.js` and add your real details:
- `email`: your contact email
- `linkedin`: your LinkedIn profile URL
- `github`: your public GitHub profile URL

Do not add private repository URLs, credentials, API keys, admin logins or customer data.

## Publish for free
### GitHub Pages
1. Create a **public** repository named `akhilchelat.github.io` (or another public portfolio repository).
2. Upload the contents of this folder (not the outer ZIP folder).
3. In GitHub, open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.

You can also deploy the folder using Netlify Drop.

## Before publishing
- Confirm every screenshot is safe to share and contains no personal/customer data.
- Replace the contact links in `config.js`.
- Verify all project claims and service availability.
- The FleetSet source repository remains private; this site does not include source code.
