# Akhil Chelat — Portfolio

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Files
- `index.html` — website content and screenshot galleries
- `styles.css` — responsive visual design
- `script.js` — navigation, contact links and screenshot lightbox
- `config.js` — public contact links
- `assets/fleetset-mobile/` — 41 FleetSet mobile screenshots
- `assets/fleetset-swagger/` — 11 FleetSet Swagger screenshots

The galleries use all 52 supplied screenshots. Keep the `assets` folders alongside the HTML file when publishing.
